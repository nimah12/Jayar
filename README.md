# 🏡 جایار

**سامانهٔ آنلاین رزرو هتل، ویلا، سوئیت و اقامتگاه در سراسر ایران — نسخهٔ نمایشی (Prototype)**

جایار یک وب‌اپ فارسی و راست‌به‌چپ است که در آن مهمان‌ها می‌توانند اقامتگاه جستجو کنند، صفحهٔ جزئیات و نظرات را ببینند و آنلاین رزرو کنند؛ میزبان‌ها هم می‌توانند اقامتگاه ثبت کنند و رزروهای دریافتی را تأیید یا رد کنند.

> ⚠️ این پروژه یک **نمونهٔ نمایشی** است: همهٔ داده‌ها در `localStorage` مرورگر ذخیره می‌شوند و **بک‌اند یا درگاه پرداخت واقعی ندارد**.

## 🛠 تکنولوژی‌ها

- **HTML + CSS سفارشی** — `css/style.css` (متغیرهای رنگی، حالت تاریک، کاملاً RTL)
- **Tailwind CSS v4** — پیکربندی مبتنی بر CSS در `css/tailwind-input.css` و خروجی تولیدشده در `css/tailwind.css`
- **جاوااسکریپت خالص** — بدون هیچ فریمورک یا کتابخانهٔ خارجی
- **Node.js** — سرور محلی (`serve.js`): سرو فایل‌های استاتیک + API ساده با ذخیره‌سازی در فایل JSON
- **فونت وزیرمتن** — محلی در `fonts/`، تحت مجوز **SIL Open Font License 1.1** (جزئیات در `fonts/LICENSE-OFL.txt`)

## 🚀 نصب و اجرا

پیش‌نیاز: **Node.js ۲۰ به بالا** (برای Tailwind v4؛ سرور `serve.js` روی هر نسخه‌ای کار می‌کند).

```bash
# ۱) نصب وابستگی‌ها
npm install

# ۲) اجرای سرور محلی (پورت ۵۸۷۱)
npm run serve
# یا
npm start
```

سپس مرورگر را باز کنید: **http://localhost:5871**

### اسکریپت‌ها

| دستور | توضیح |
|---|---|
| `npm run serve` / `npm start` | اجرای سرور محلی (استاتیک + API) روی پورت ۵۸۷۱ |
| `npm run build:css` | بازتولید `css/tailwind.css` از `css/tailwind-input.css` |
| `npm run build:meta` | بازنویسی تگ‌های SEO همهٔ صفحات از `site.config.js` (بعد از تغییر دامنه) |
| `npm run watch:css` | بازتولید خودکار CSS هنگام تغییر فایل‌ها (برای توسعه) |
| `npm test` | تست خودکار API با `node:test` (سرور در پورت و دیتابیس جداگانه اجرا می‌شود) |

> بعد از هر تغییر در HTML/JS، اگر کلاس Tailwind جدید اضافه کردید، `npm run build:css` را اجرا کنید.

**تغییر دامنهٔ سایت:** فقط `SITE_URL` را در `site.config.js` عوض کنید و `npm run build:meta` را اجرا کنید — تگ‌های `canonical`، `og:url` و `og:image` در هر ۸ صفحه به‌طور خودکار با دامنهٔ جدید بازنویسی می‌شوند (اجرای دوباره بدون تغییر بی‌اثر است).

## 🔑 ذخیره‌سازی (سرور + localStorage)

لایهٔ ذخیره‌سازی (`js/store.js`) **حالت دوگانه** دارد:

- **آنلاین (پیش‌فرض):** وقتی سرور اجرا می‌شود، اقامتگاه‌ها، رزروها و حساب‌های میزبان روی سرور در `data/db.json` ذخیره می‌شوند و **بین دستگاه‌ها مشترک‌اند**. تغییرات به‌صورت خودکار با سرور همگام می‌شود.
- **آفلاین (fallback):** اگر سرور در دسترس نباشد (مثلاً باز کردن مستقیم فایل‌ها)، همه‌چیز مثل قبل در `localStorage` ذخیره می‌شود و اپ بدون تغییر کار می‌کند.

کلیدهای `localStorage` (برای علاقه‌مندی‌ها، جستجو و نشست میزبان):

| کلید | محتوا |
|---|---|
| `jayar_properties` | اقامتگاه‌های میزبان‌ها (وقتی آفلاین) |
| `jayar_bookings` | رزروها (وقتی آفلاین) |
| `jayar_host` | میزبانِ واردشدهٔ فعلی (نشست مخصوص دستگاه) |
| `jayar_hosts` | حساب‌های میزبان (وقتی آفلاین) |
| `jayar_favs` | آی‌دی اقامتگاه‌های علاقه‌مندی (همیشه محلی) |
| `jayar_search` | آخرین جستجوی کاربر (همیشه محلی) |

### API

| متد و مسیر | کار |
|---|---|
| `GET /api/bootstrap` | دریافت همهٔ داده‌ها در یک درخواست (properties، bookings، hosts) |
| `GET /api/properties` | فهرست اقامتگاه‌های میزبان‌ها |
| `POST /api/properties` | ثبت اقامتگاه جدید |
| `PATCH /api/properties/:id` | ویرایش اقامتگاه |
| `DELETE /api/properties/:id` | حذف اقامتگاه |
| `GET /api/bookings` | فهرست رزروها |
| `POST /api/bookings` | ثبت رزرو جدید |
| `PATCH /api/bookings/:id` | تغییر وضعیت رزرو (تأیید/رد) |
| `POST /api/hosts/login` | ورود/ثبت‌نام میزبان بر اساس شمارهٔ تماس (find-or-create) |

## 🧭 جریان کاربری

**مهمان:**
1. جستجو بر اساس شهر/نوع/ظرفیت در `index.html` → ورود به جزئیات
2. انتخاب تاریخ‌ها → مشاهدهٔ محاسبهٔ خودکار قیمت (قیمت شب × تعداد شب + ۱۰٪ هزینهٔ سرویس)
3. ثبت رزرو با کد رزرو → رزرو با وضعیت «در انتظار» برای میزبان ارسال می‌شود

**میزبان:**
1. ورود/ثبت‌نام با نام و شمارهٔ تماس در `host.html`
2. ثبت اقامتگاه (نوع، شهر، قیمت، امکانات، توضیحات) — بلافاصله در جستجو نمایش داده می‌شود
3. مشاهدهٔ رزروهای دریافتی و تأیید (`ok`) یا رد (`cancelled`) آن‌ها

## 🧩 نکات فنی

- **کارت اقامتگاه یک‌جا:** `J.cardHTML(p, idx)` در `common.js` منبع واحد قالب کارت است — هم در صفحهٔ اصلی و هم در علاقه‌مندی‌ها استفاده می‌شود. برای تغییر ظاهر کارت‌ها فقط همین‌جا را ویرایش کنید.
- **تصاویر محلی:** `J.img(seed)` با هش کردن seed یکی از ۱۵ تصویر `images/` را برمی‌گرداند؛ برای افزودن اقامتگاه جدید نیازی به آپلود عکس نیست.
- **داده‌های نمونه:** ۱۰ اقامتگاه اولیه در `js/data.js` تعریف شده‌اند و همیشه در فهرست هستند؛ اقامتگاه‌های میزبان‌ها روی آن‌ها اضافه می‌شوند (`J.getProperties()`).
- **امنیت ورودی‌ها:** همهٔ مقادیر کاربر قبل از درج در HTML با `J.escape` پاک‌سازی می‌شوند.
- **هم‌زمانی سرور:** نوشتن `db.json` با یک قفل (صف) و به‌صورت اتمی (فایل موقت + rename) انجام می‌شود؛ درخواست‌های هم‌زمان از چند دستگاه بدون ازبین‌بردن دادهٔ یکدیگر کار می‌کنند.
- **اعداد و تاریخ:** با `Intl` به ارقام و تقویم فارسی فرمت می‌شوند (`J.fmtNum` / `J.fmtDate`).

## ⚠️ محدودیت‌های نسخهٔ نمایشی

- بک‌اند سادهٔ فایل‌محور (JSON) بدون دیتابیس و احراز هویت واقعی — برای استقرار واقعی باید با یک دیتابیس و سیستم لاگین امن جایگزین شود.
- بدون درگاه پرداخت؛ رزرو فقط یک درخواست است که میزبان باید تأیید کند.
- تصاویر همهٔ اقامتگاه‌ها از استخر ۱۵تایی محلی انتخاب می‌شوند (عکس واقعی هر ملک نیست).
